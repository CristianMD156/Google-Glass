🕶️ Projeto Google Glass - HTML5

Site institucional desenvolvido com HTML5, CSS3 e JavaScript, apresentando informações, especificações, fotos e conteúdos multimídia sobre o Google Glass.

Projeto focado em prática de estruturação semântica, organização de diretórios e recursos multimídia na web.

🚀 Tecnologias Utilizadas

HTML5

CSS3

JavaScript

Áudio e Vídeo em múltiplos formatos (.mp3, .ogg, .mp4, .aac)

Fonts customizadas (.otf, .ttf)

🎯 Objetivo do Projeto

O projeto tem como objetivo:

Aplicar tags semânticas do HTML5

Trabalhar com layouts estruturados

Implementar menus interativos com JavaScript

Incorporar áudio e vídeo

Organizar arquivos de forma modular

Criar páginas interligadas com navegação estruturada

🖥️ Páginas do Site

🏠 Home (index.html)

⚙️ Especificações técnicas (specs.html)

📷 Galeria de fotos (fotos.html)

🎬 Conteúdo multimídia (multimidia.html)

🎨 Recursos Implementados

Galeria de fotos estilizada

Formulário de contato estilizado

Organização de CSS por página

Separação de textos em diretório próprio

Estrutura modular de imagens e mídias

▶️ Como Executar

Baixe o projeto ou clone o repositório

Abra o arquivo:

index.html

Execute no navegador de sua preferência

Não é necessário servidor ou instalação adicional.
